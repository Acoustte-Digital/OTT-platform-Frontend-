# StreamFlix Frontend

A modern OTT platform frontend built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**.

## Pages
- `/` Home (hero + carousels)
- `/browse` Browse with category filters
- `/watch/[id]` Dynamic video player page
- `/login` Login form with validation
- `/signup` Signup form with validation

## Run locally
```bash
npm install
npm run dev
```

## Validation
```bash
npm run lint
npm run build
```
