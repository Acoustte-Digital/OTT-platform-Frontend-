# StreamX OTT Frontend

Modern OTT platform frontend built with **Next.js App Router**, **React**, **TypeScript**, and **Tailwind CSS**.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Implemented pages

- `/` Home (hero + trending/popular/recommended carousels)
- `/browse` Category-filtered movie grid with skeleton loading
- `/login` Login form with client-side validation
- `/signup` Signup form with client-side validation
- `/watch/[id]` Dynamic watch page with HTML5 video player and related content
